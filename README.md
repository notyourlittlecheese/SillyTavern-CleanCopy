# 酒馆净文复制 · CleanCopy

每层消息的编辑图标旁增加一个 **扫帚图标**。点击后复制当前显示的净文，不修改聊天记录。

## 安装

在 SillyTavern 的「扩展 → 安装扩展」中输入：

https://github.com/notyourlittlecheese/SillyTavern-CleanCopy

安装后刷新页面。无需构建、API Key、后端插件或额外依赖。

## 复制规则

- 读取当前消息 `.mes_text` 的实际渲染结果，因此跟随酒馆已经生效的显示正则、当前 swipe 和编辑结果，不重新对原文执行正则。
- 输出纯文本并保留段落、换行；排除代码块、行内代码、脚本、样式、HTML 注释、原生推理区域及隐藏元素。
- 默认 `content` 去标签保留正文，`thinking` 和 `details` 整段排除。
- 在「扩展 → 净文复制」中可停用、删除规则或添加标签，每个标签可选择保留文字或整段排除。
- 禁用 `details` 排除规则后，折叠区域只复制标题；展开区域复制当前可见文字。
- 规则针对渲染后仍存在的标签，以及被转义显示的同名标签。若其他插件已删除标签但保留内部文字，无法从渲染结果恢复其原始归属；请使用酒馆显示正则隐藏该部分。
- 不读取 iframe 内的独立页面、图片文字、CSS 伪元素或 Shadow DOM 内容。不根据内容猜测任意未标记的程序代码。

## 样式与兼容

消息按钮使用原生 `mes_button fa-solid fa-broom` 类，与编辑按钮处于同一工具栏；不覆盖颜色、大小、背景或悬停效果。作用于原生消息按钮的主题规则会直接生效。仅针对 `.mes_copy` 单独写的主题规则不会自动作用于新的扫帚按钮。

基于 SillyTavern release 分支的消息结构和 `SillyTavern.getContext()` 接口实现。建议使用提供该接口的近期版本。HTTP 环境或剪贴板 API 被拒绝时尝试浏览器传统复制方式，失败会明确提示。
