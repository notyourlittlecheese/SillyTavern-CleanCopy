# 酒馆净文复制 · CleanCopy

每层消息的编辑图标旁增加一个 **羽毛图标**。短按复制当前显示的净文，长按选择要补入的标签内容；不修改聊天记录。

## v1.1.0：长按选择

- 短按：维持原来的净文复制。
- 长按约半秒：打开选择菜单。电脑也可以右键，键盘可以按 Shift+Enter。
- 快捷组合：正文 + thinking、正文 + details、正文 + thinking + details。
- 自定义组合：勾选标签，也可输入临时标签名（空格、英文逗号、中文逗号或顿号分隔）。设置中添加的标签会自动出现在菜单里。
- Esc、取消或点击弹窗外关闭，不复制。长按松手不会额外触发短按复制；拖动或触摸取消会取消长按。
- 固定使用羽毛矢量图标，无图标选择设置。

## 安装

在 SillyTavern 的「扩展 → 安装扩展」中输入：

https://github.com/notyourlittlecheese/SillyTavern-CleanCopy

安装后刷新页面。无需构建、API Key、后端插件或额外依赖。

## 复制规则

- 读取当前消息 `.mes_text` 的实际渲染结果，因此跟随酒馆已经生效的显示正则、当前 swipe 和编辑结果，不重新对原文执行正则。
- 输出纯文本并保留段落、换行；排除代码块、行内代码、脚本、样式、HTML 注释、原生推理区域及隐藏元素。
- 默认 `content` 去标签保留正文，`thinking` 和 `details` 整段排除。
- 在「扩展 → 净文复制」中可停用、删除规则或添加标签，每个标签可选择保留文字或整段排除。
- 禁用 `details` 排除规则后，折叠区域只复制标题；展开区域复制当前可见文字。
- 长按组合的正文仍然使用显示正则处理后的渲染文字；额外标签从当前楼层保存的原文中提取，因此显示正则隐藏/折叠的段落也能补回。补入的段落接在正文后面，保留原文中的先后顺序，去标签并转为纯文本，不再次执行显示正则。
- 选中的标签优先于短按的排除规则；没有选中的排除标签、HTML 注释和代码仍会过滤。嵌套标签一起选择时只提取外层一次。
- 若某个标签只存在于渲染结果（例如显示正则生成的 `details`），会从其渲染结构中补取折叠文字，不实际展开页面。与原文补入段落完全重复的内容会去重；复杂的第三方模板可能无法精确对应。
- 若正则已永久改写保存的消息，原文和页面均没有保留的内容无法恢复；未找到选中标签时会提示。
- 规则针对渲染后仍存在的标签，以及被转义显示的同名标签。若其他插件已删除标签但保留内部文字，无法从渲染结果恢复其原始归属；请使用酒馆显示正则隐藏该部分。
- 不读取 iframe 内的独立页面、图片文字、CSS 伪元素或 Shadow DOM 内容。不根据内容猜测任意未标记的程序代码。

## 样式与兼容

消息按钮使用原生 `mes_button` 类，与编辑按钮处于同一工具栏；不改变工具栏排列方向。羽毛 SVG 使用 `1em` 大小和 `currentColor`，跟随按钮的字号和颜色，不覆盖背景或悬停效果。作用于原生消息按钮的主题规则会直接生效。仅针对 `.mes_copy` 单独写的主题规则不会自动作用于新按钮。菜单中的按钮横向排列，小屏幕允许换行。

基于 SillyTavern release 分支的消息结构和 `SillyTavern.getContext()` 接口实现。建议使用提供该接口的近期版本。HTTP 环境或剪贴板 API 被拒绝时尝试浏览器传统复制方式，失败会明确提示。
